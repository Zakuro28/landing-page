# Zacc Websites

Landing page for my web development services: business websites, landing pages, online stores and ongoing site care.

## Built with

- [React](https://react.dev) + [Vite](https://vite.dev) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)
- [Motion](https://motion.dev) for animation
- [Lucide](https://lucide.dev) icons
- Animated components adapted from [React Bits](https://reactbits.dev): BlurText, SpotlightCard, Magnet
- Aura background inspired by [Aura Gradients](https://auragradients.vercel.app)

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build for production

```bash
npm run build
```

The site is output to `dist/`, ready for Vercel, Netlify or GitHub Pages.

## Editing

Name, email, phone and social links live in `src/config.ts`. Each page section is its own file in `src/sections/`.
